# 方法、适用范围与失败证据

## 结论范围

验证对象是一个具体的公开 Sorscher 单环境 RNN，以及原第一阶段的缩短训练本地 RNN。最终支持的是公开模型中固定 483 单元子群、静止输入20步终态的**环面一致持久拓扑**。随机运动末步的原始样本集合没有相同的稳健 `(1,2,1)` 区间；全部神经元集合也没有通过同样统计门槛。没有把这些失败省略、换成 UMAP 图片或改用平均图后宣称原始状态成功。

Betti 数不是拓扑类型的唯一标识。域 47 与域 2 的一致性排除某些只在特定域上出现的假匹配，但不能证明全局同胚。IID 维度、局部位置 Jacobian 秩和预先预测的周期位移是支持性证据；周期误差并不为零，也未证明模型具有严格动态不变的环面吸引子。只把结果与已发表生物网格细胞研究报告的拓扑特征比较，未重新分析生物放电数据。

## 检查点与实现核对

Schøyen 作者仓库 main/v1 和 release 未见完整检查点，保留查到的仓库树与发布元数据。取得 Ganguli Lab 的公开权重，提交 `401dd6b5e20a754267b16eeb5bd88239b9af33e9`。其四个 float32 矩阵形状为 `(512,4096),(2,4096),(4096,4096),(4096,512)`，包含全部无偏置编码、递归输入、递归与读出参数。通过受限制的 NumPy 数组反序列化读取，并核验 Git blob SHA 与 SHA256。

2025 年 `yuling-wu/hierarchy_band_grid` 提交 `55bf433e6ba5f64035ed7a12a5a464f7106ac585` 的示例权重 Git blob SHA 完全相同，所以不是第二个训练种子。权重足以完整推理，但公开文件不含原优化器、随机种子或训练步数。不能根据源码默认值断言这个权重严格训练了某个预算。

四矩阵转置到 PyTorch 同构 RNN；推理方程仍为 `h0=We p0`，`h[t]=ReLU(Wg h[t-1]+Wv u[t])`，`logits=Wd h[t]`。参考公开 PyTorch RNN 和原数组独立矩阵递归均核对通过。必须使用随权重发布的 place-cell centers；当前源码默认重新采样的布局与该文件不同。物理坐标由 `[-1.1,1.1]` 平移到 `[0,2.2]`，模型与目标使用同一个布局。

公开模型独立 2048 轨迹平均定位误差约 4.48cm，解码下限 4.14cm；零输入、打乱输入约 19.75cm、26.20cm。旧模型约 8.86cm，下限4.32cm，约97.8%末步激活为零。公开模型约68.8%末步激活为零。权重谱、稀疏性与格点响应差异只是诊断；预算、学习率、正则、布局等混杂，未作孤立因果归因。

没有新增完整训练：公开模型已给出可靠的条件性拓扑证据，因此未为获得环面而反复改训练参数。RTX 5060 的原规模训练／精度基准仅为运行可行性测试，不能计作训练复现。旧模型的完整 optimizer/RNG 检查点作为本轮失败基线保存；只保留本轮复算所需基线，不保留整个旧版本成果包。

## 发现与留出分离

旧数据以初始位置组划分：2048组的四种条件一起分配到发现1024组、验证512组、确认512组；主拓扑检验只取每个留出组的一条随机运动轨迹，不能把配对条件当独立重复。公开模型的发现集为10000条新随机轨迹，seed=72101；最初验证／确认各2048条，seed=72102/72103。

发现集形成32×32地图，只用末10步（11–20），缺失空间格点以最近已占用格点填充并保存占用计数。排除发现图空间方差为零的单元，以及活跃单元平均活动高于99.75百分位的高基线单元。格分数调用原作者 GridScorer，内半径0.2，外半径0.4–1的10个环。`GCS>0.3` 是预定义格样响应筛查，不是生物细胞鉴定或环面证据。

旋转特征遵循作者 notebook 的实现：对归一化地图的空间自相关，在360个角度以最近邻旋转计算圆盘内 Pearson 相关；UMAP Euclidean、neighbors=20、min_dist=0.05、seed=72003，DBSCAN eps=0.5、min_samples=30。正文对地图／自相关的表述略有差别，这里明确依照公开 notebook 的 SAC 操作。UMAP 只用于单元响应分类，未用于主 PH 数据。

## 方法版本与防止挑结果

v1 在发现图上取 Fourier 轴向功率集中的单元，合并主频附近的三方向群，得到970单元；原空间验证与确认均失败。PCA6-cosine 敏感性有正特征，不能替代原空间失败。

v2 更接近原论文的“先旋转聚类，再分类条带群”，用固定发现集定量替代手选：簇不少于30单元，至少半数为预定义条带样单元，轴向圆标准差≤15度、频率 CV≤0.2；三簇角间隔60±15度，频率中值差≤20%，有符号波矢闭合误差≤10%。在所有合格组合中选单元数最大者，平局按标签序；没有读取 PH 值。这些规则产生唯一组合5、16、17，212＋98＋173＝483单元，波矢闭合误差约0.94%。原论文的2、12、15是其特定数据的手选标签，不能直接照搬。

v2 用全新 seed=72502/72503，每组4096初位，静止与随机运动配对。静止的384代表点检验未通过，512点部分通过；此失败保留。额外768/1024点的旧数据诊断显示静止更稳定，仍不能回头改 v2 验收。

v3 因此保持483掩码、所有统计门槛不变，只增加分辨率，并在另一批完全新样本上确认：seed=72802/72803，每组8192初位，静止／随机运动分开报告。主768代表点，1024点和域2为敏感性检查。十个来源／方法／条件假设槽在每个留出集统一 Holm 校正；无合格候选群的槽以p=1计入。探索性的全群／格样群／每个旋转簇结果完整保留，但不拿“最好看的簇”重新宣称验收。

## 原空间持久同调与统计量

主检验直接使用固定候选单元的**未做空间平均、未做 PCA/UMAP 的原始终态激活**。减去发现集均值，以单一 RMS 因子缩放；不逐单元标准化。Euclidean 距离采用float32 GPU Gram矩阵，截去平方距离的负舍入，子样本与float64距离核对。固定从第0行开始最远点抽样；每个随机化样本重新抽样代表点。

Ripser H0/H1/H2，主系数域47，域2复核。统一的计算截断为代表点非对角距离中位数，不根据持久图挑参数。保存所有条带及右删失标记；最终两主H1及主H2没有右删失，H0的单一无穷类为连通分量。

门槛：存在 `beta=(1,2,1)` 的共同区间，长度≥中位距离的0.05；第二长H1与最长H2的截断持久长度均≥0.15；H1第二／第三、H2第一／第二长度比均≥2。全部满足才令统计量为两主要归一化持久长度的较小值，否则为0。只出现某个极短 `(1,2,1)` 区间不足以通过。

随机化在整个留出集内逐单元独立置换样本，保持每个单元的边缘分布和候选掩码，破坏群体配合；每次重做最远点选择。原检验199次，plus-one p=(1+超越数)/(B+1)。零统计量的单侧p恒为1，另做19次诊断而非浪费199次。高维空对照H2可能非常昂贵：若先计算的必要H1条件不满足，完整联合统计量必为0；若“截断值−最小边距离”已小于0.15，也能严格保证所有H1截断持久长度不达门槛。记录未算维度为未算，不捏造H2。否则仍计算完整H2。这些逻辑短路不改变联合统计量。

正控制为Clifford环面、三方向合成条带人口；负控制为平面、球面和独立置换。合成控制不是RNN数据。球面的H2不能单独算环面，必须同时有两个独立持久H1。

原199次检验两组静止均p=0.005，Holm p=0.05。追加固定999次独立随机化精度审计（seed73101/73102）保持掩码、样本、距离、代表点和门槛不变，不能挽救原检验失败；两组均0超越，p=0.001，保守10倍p=0.01，单侧95%真实尾概率上限约0.003（10倍约0.03）。原检验和复核均报告，不把原分辨率隐藏。

## 维度与几何支持

更早PH诊断中的 TwoNN 基于最远点样本，采样偏差会抬高邻距比估计，不能作最终内在维度。最终使用4096个 IID 随机点：静止 TwoNN约2.33/2.36、kNN k=10估计约2.02；随机运动约4.9–5.3。更大邻域会混合厚度、近邻折叠与曲率，静止k=40约2.75。

256初位有限差分 Jacobian 的局部秩均为2，第二／第一奇异值中位比约0.679。静止终态本来就是两个初始位置变量的确定性映射，秩支持局部二维组织，不能单独证明全局环面。发现图预测的两条物理周期位移，候选激活距离中位数约0.61/0.59，同长度45度旋转控制约1.53/1.24；是近似周期性，不是精确粘合或全局数学证明。

## 完整逐步记录与解释界限

验收静止子群后，另采seed73001的1024个初位，静止与随机运动配对，全程不重置、不更新权重，保存所有 `H[21,2048,4096]` 及固定483单元子群。初态是线性位置编码，可为负，第一次ReLU发生在步骤1；第0步无运动输入，其读出未被训练。作者名为velocity的输入实际已乘dt：这里米／步，物理速度=input/0.02。

固定发现集PCA基和全局轴用于每一步，前三维只解释约41.8%发现集方差。单样本轨迹、固定步骤集合、集合的配对距离变化分别保存。静止物理位置不变但初态表征会松弛；运动样本物理位置变化、输入和历史会增加维度。NN到独立静止参考集合、质心与距离图变化不等于连续流形形变，更不是测地线。没有逐步重新拟合UMAP，也没有任何Ricci/Hamiltonian/测地流拟合。

输入轨迹是非周期方形环境的模拟运动，保留软墙规则可微小越墙的行为；没有把物理环境强制设成环面。所有关键模型、数据、协议与失败结果可检查，重放验证包括575个原始分块，H最大差0，读出最大差约1.37e-6。严格跨平台字节相同不作保证。
