# 数据方法与证据边界

## 模型与来源

模型源码 main 提交 `3b0a34da4bac1e894796fe869d064cd53bfd9faa`；论文 v1.0 提交 `66e92c6c65708011abb8f0a7448c7eb7c7a109b6`。RNN、位置细胞、损失和数据处理文件的 Git blob 哈希相同。`original/` 为导入文件，`upstream/` 保留完整仓库快照；MIT 许可证随原代码保存。轨迹源提交 `42c8cef3978573bfeed0468b4e3cc1cb821bce0d` 随 `rat_original/` 保存。Zenodo 只列出代码 zip；该 zip 传输中断，未把部分下载当作完整源码。仓库 main 与 v1.0 的完整树均无检查点数组，release 无附件；这个结论限定于已检查的公开位置。

递归方程为 `h0 = We p0`，`h[t] = ReLU(Wg h[t-1] + Wv u[t])`，`logits[t] = Wd h[t]`，输出为 softmax。编码、递归、读出均无偏置。初态可为负值，不能提前施加 ReLU。训练采用作者的概率分布交叉熵加正 L2；论文排版公式中的负号与正文及实现不同，本轮遵从实现。

作者 `train()` 覆盖了 PyTorch 的模式切换接口，因此本轮使用外部可配置训练循环、调用作者 `loss_fn()`；固定权重采集直接调用 `Module.train(model,False)` 并关闭参数梯度，不使用作者的训练日志、对新环境评估或依赖未发布文件的 Experiment 初始化。

## 训练与随机性

完整模型的初始化种子 20261012、训练轨迹种子 3302、位置细胞种子 0。Adam 默认 betas/eps，学习率 1e-3，递归 L2 1e-6，批次 200，序列 20。每批使用新生成的随机轨迹。每 250 批在固定门槛集 seed=991、N=512 上检查；至少 2000 批后，平均定位误差小于 0.095m 且低于不动基线的 55% 即停止。实际在第 4750 批停止，相当于 950000 条训练轨迹。最终 seed=992、N=1024 为单独报告集，不参与早停。

零输入对照把相同初态的所有位移置零；打乱输入对照在样本之间置换完整运动输入序列，保持原初态和评估目标。不动基线是初始目标位置细胞活动经作者 top-3 解码后的固定位置。解码下限同样使用作者 top-3 解码真实目标。这些对照支持网络利用了输入进行短时域积分，不证明所有神经元是网格细胞。

训练启用确定性算法、固定 cuBLAS workspace 配置，关闭 TF32 和 cuDNN benchmark。`initial.pt` 保存随机初始权重；`last.pt` 包含训练步数、模型、优化器、NumPy generator、torch CPU/CUDA RNG 状态。`place_cell_centers.npy` 是实际使用的布局，加载时优先使用保存的中心。无法把单次本地训练等同于多种子、主论文三环境和完整预算的重复实验。

成功小试验使用 Ng=256、seed=20261011、训练 seed=3301，其余采用加速设置，6000 批停止。最初的 Ng=256、batch=64、L2=1e-4 短试验未学会积分；完整日志和权重保留为失败证据。

## 轨迹与索引

采集 seed=20261011。在 2.2×2.2m 空间内，以分层网格和固定随机偏移产生 2048 个不同初始位置；每个位置配四类轨迹，样本 ID 分段排列。分层网格的最后一行不完全填满，因此实际覆盖率由数据计算，未声称理想均匀覆盖。核心各条件 N=2048；扩展在各条件 ID 范围均匀选取 256 个样本，共 1024 条。

静止条件所有位移为零。匀速条件方向不变，速度先抽取 0.2–0.8m/s，再按到墙距离降低，以保证 160 步期间不转弯；所以部分轨迹实际速度低于初始抽样范围，以保存值为准。闭合路径为半径不超过 0.06m、周期 20 步的圆，靠墙处缩小半径；第 20/40/80/160 步返回初位。随机运动采用作者的 Rayleigh 速度、角度随机游走和软墙修正规则；步长 dt=0.02s，速度尺度 0.13×2π、角速度标准差 11.52。向量化矩形墙规则已与作者标量代码在 505 个位置/角度条件对照验证。

随机轨迹生成保留作者可稍微越过墙后返回的行为，没有强行裁剪位置。浮点位置累积为 float32，随机数调用顺序为批向量形式，与作者逐条生成器不同；分布与方程兼容，不能宣称同种子原始轨迹逐字一致。

`trajectory_parameters` 的列为初始角度、恒定速度、圆半径、圆心 x/y、周期。字段按条件解释：静止不使用；匀速使用角度/速度；圆使用相位/半径/圆心/周期；随机使用实际初始朝向。无效列填零，不能当作测得参数。`initial_position`、`initial_place_activity`、`H[0]` 和全部输入历史完整保存。第 0 步的输入/速度为零占位，`input_present[0]=False`；不是额外执行了一次零输入递归。

模型只接收初态位置细胞活动和每步二维位移；目标位置数组仅用于训练标签和事后评价。采集从第 0 步连续运行，没有分段重置、逐步教师强制或在线更新权重。40、80、160 为同一连续扩展的前缀，前三个视图并不是三次独立实验；`within_training_horizon` 显式标记每个状态。静止、匀速与圆属于受控输入条件，与训练随机运动分布不同，即使步数在 20 步内也不应称为 IID 测试。

## 张量与复算

每个实际 HDF5 分块具有 `H[step,local_sample,neuron]`，float32，gzip level=1 + shuffle 为无损存储；没有神经元筛选、四舍五入或只存投影。`core_T20.h5`、`exploratory_T160.h5` 是相对路径的 HDF5 Virtual Dataset，整合样本轴，读取时不需一次加载全张量。

动态字段包括 H、logits、输出概率、真实位置细胞活动、预测/目标解码位置、误差、二维位置、模型输入和物理速度。样本字段包括 ID、条件、初位、初态位置编码、运动参数。步骤字段包括 step、time_s、input_present、within_training_horizon。除 H0 的结构约定外，输出读出第 0 步未被训练，因此其定位误差不能与后续训练目标混淆。

核心与扩展列序不同，必须按 sample_id 对齐。对一条轨迹，固定 sample_id 查看 H[:,i,:]；对固定步的表征集合，查看 H[t,:,:]；跨步集合比较应保持 ID 对应，另可使用 `paired_step_changes.json` 中的原始全神经元位移与集合质心变化。

验证对每个分块检查 SHA256、全部数值有限性、概率归一化、位置差分与输入、速度单位。随后从保存初态与输入对该块全部样本重算所有隐藏状态和输出，并用独立逐步矩阵运算核对作者 RNN。扩展前 21 个状态按 ID 与核心逐一核对。在本机记录环境下主数据三类重放差均为 0；这是当前硬件/软件结果，不是跨平台浮点字节保证。

## 初步几何与限制

主数据每条件全部样本都用于位置覆盖、任务表现、全神经元稀疏/不活跃比例。内在维度与 PCA/PH 筛查使用每条件均匀抽取 128 个样本，其抽样 ID 可检查。TwoNN 在原始全神经元 Euclidean 距离上计算，去除完全相同向量，邻距比对数去除上下各 10%；结果依赖尺度、采样及边界，仅作筛查。参与比描述方差展开，不等同于拓扑维度。第 20 步 TwoNN 约 2.71–4.81，参与比约 19.4–22.8，不能据此宣布确定的二维环面。

固定步骤 5/20 的静止条件在全神经元空间、以 RMS 半径归一化距离做 H0/H1/H2 Vietoris–Rips PH。另给同样样本数量的合成环面与平面作计算流程对照；它们不是 RNN 数据，也不是统计检验。没有模块识别、显著性零分布或多种子复现，未作环面验收。PH 不使用 3D PCA 点云，也没有挑选高网格分数或高活动神经元。

唯一 PCA 以核心抽样的全部 0–20 状态合并拟合，完整 4096 个神经元不做逐神经元标准化；相同均值、基向量用于所有步和探索步。均值、32 个基向量、方差解释量、点坐标和样本 ID 保存在 pooled_pca.npz，前三维约解释 26.1%。交互图在所有按钮使用相同的 1024 个扩展 sample_id，保持轴范围、纵横比和坐标基一致；静态核心图使用固定 512 个抽样 ID，也固定同一轴范围。单轨迹线和固定步集合视图分开显示。3D 上看到的收缩、展开和轨迹不是全维流形形变的证据。

验收范围是“已取得完整、可对应、可复算的实际 RNN 状态数据”。候选大流形可在全维数据与离散步骤索引上构造；其存在性、统一性、连续几何动力学和神经/思维解释均未得到验证。
